Independent Reader

This reader does not use the Writer application. It fetches the record from Swarm, validates its portable format, and renders it — on its own.

  1. Fetching record from Swarm
  2. Validating portable format
  3. Rendering record

How independence is proven

Own entrypoint (reader/index.html), own download (GET /bytes/<reference>), own parse + validate, own render. The only shared module is ../shared/format.js (standalone schema). The authoring app lives separately and shares no components, storage helpers, or rendering code with this page.
